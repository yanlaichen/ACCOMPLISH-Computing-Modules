# Introduction to Sensor Data Analytics and Anomaly Detection in Manufacturing

The main module is developed primarily for undergraduate students and is
organized as a chapter-based tutorial. The intent is to introduce students to
manufacturing sensor data and provide hands-on experience with data analytics
using Python. Three case studies are included:
* Equipment energy/power anomaly detection
* Predictive maintenance classification
* CNC/process signal feature extraction

## Contents

The files include the main module on sensor data analysis and anomaly detection, student activities, instructor guidance, example datasets, Jupyter notebook files, links to relevant open-access datasets and Python resources, and an advanced module on anomaly detection.
